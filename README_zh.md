# Homepage

[English](README.md) | 中文

个人主页 — 基于 **Vue 3 + Vite 6** 的内容驱动型单页应用。

## 技术栈

- **Vue 3** — Composition API + `<script setup>`
- **Vite 6** — 构建工具，含 JSONL 数据生成插件
- **Ant Design Vue 4** — UI 组件（仅 ConfigProvider + Menu）
- **markdown-it** — Markdown 渲染与锚点
- **Shiki** — 语法高亮（VS Code 风格）
