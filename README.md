# Homepage

English | [中文](README_zh.md)

Personal homepage — a content-driven single-page application built with **Vue 3 + Vite 6**.

## Tech Stack

- **Vue 3** — Composition API + `<script setup>`
- **Vite 6** — build tool with JSONL data-generation plugins
- **Ant Design Vue 4** — UI components (ConfigProvider + Menu only)
- **markdown-it** — Markdown rendering with anchors
- **Shiki** — syntax highlighting (VS Code style)
