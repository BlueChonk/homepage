# cecilia4412.github.io

cecilia 的个人主页，基于 GitHub Pages 托管的纯静态单页站点。

**在线访问**：<https://cecilia4412.github.io>

## 页面内容

- **Hero**：GitHub 头像、打字机轮播简介、社交链接（GitHub / Bilibili / Steam / 邮箱）
- **项目仓库**：bert-from-scratch-zh、asr-study、deploy-notes、EchoBot 的卡片式导航
- **关注领域**：GitHub Star 清单的方向标签云（Agent / RAG / TTS / OCR / ASR 等）

## 本地预览

直接双击 `index.html`，或在仓库目录启动任意静态服务器，例如：

```bash
npx serve .
```
